# 🧠 Room Overview

This hands-on challenge places you in the role of a security engineer responsible for auditing an internal AI assistant named **Bastion**. Your objective is to identify multiple AI security vulnerabilities, understand their root causes, and recommend the appropriate security controls to harden the system.

Unlike previous rooms that focused on exploitation, this challenge emphasizes **AI security assessment and remediation**.

# 🛡️ AI Security Relevance

Securing an AI assistant requires more than filtering prompts. Organizations must implement multiple defensive layers including strict access controls, hardened system prompts, retrieval restrictions, validation mechanisms, and continuous security assessments.

Effective AI security combines preventive controls, monitoring, and regular auditing to reduce the attack surface and limit the impact of emerging AI threats.
