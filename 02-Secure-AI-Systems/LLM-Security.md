# 🧠 Room Overview

This room explores the security risks associated with Large Language Models (LLMs). It examines threats targeting data, models, systems, and users while introducing best practices for securing LLM-powered applications.

---

# 🎯 Learning Objectives

- Understand the LLM attack surface
- Identify data-based threats
- Explore model-based vulnerabilities
- Learn system-level security risks
- Recognize user-focused attacks against LLMs

---

# 📌 Room Summary

### Task 1 — Introduction
- Overview of LLM Security and the expanding attack surface of modern AI applications.

### Task 2 — Data-Based Threats
- Learned how training data, retrieval data, and user inputs can introduce security risks such as data poisoning and sensitive information exposure.

### Task 3 — Model-Based Threats
- Explored attacks targeting AI models, including model theft, adversarial examples, model inversion, and prompt manipulation.

### Task 4 — System-Based Threats
- Studied security risks affecting APIs, plugins, infrastructure, authentication, and AI application architecture.

### Task 5 — User-Based Threats
- Learned how attackers exploit users through prompt injection, phishing, social engineering, and malicious AI interactions.

LLMs introduce unique security challenges that span data, models, infrastructure, and user interactions. Understanding these threats is essential for building secure AI applications and defending against attacks targeting modern language models.
