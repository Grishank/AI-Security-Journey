# 🧠 Room Overview

This room introduces the most common security threats affecting Artificial Intelligence systems and Large Language Models (LLMs). It explores how attackers exploit AI models and the defensive techniques used to build secure AI applications.

---

# 🎯 Learning Objectives

- Understand common AI security threats
- Explore vulnerabilities in AI models
- Learn how attackers misuse AI
- Understand defensive AI techniques
- Learn security best practices for AI systems

---

# 📌 Room Summary

### Task 1 — Introduction
- Overview of AI Security and modern AI-related threats.

### Task 2 — Vulnerabilities in AI Models
- Learned how AI models can be manipulated through data poisoning, prompt injection, model theft, and adversarial inputs.

### Task 3 — AI-Enhanced Attacks
- Explored how attackers leverage AI to improve phishing, malware generation, social engineering, and automated cyberattacks.

### Task 4 — Defensive AI
- Learned how AI can assist defenders through threat detection, anomaly detection, malware analysis, and security automation.

### Task 5 — Securing AI
- Explored best practices for protecting AI systems, including secure model deployment, input validation, monitoring, and access control.

### Task 6 — Practical
- Applied the concepts learned by completing practical exercises on AI security threats and defenses.
