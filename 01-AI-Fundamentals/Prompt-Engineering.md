# 🧠 Room Overview

This room introduces the fundamentals of **Prompt Engineering**, explaining how Large Language Models (LLMs) interpret prompts and how carefully designed prompts improve AI responses. It also covers prompt structures, system prompts, and advanced prompting techniques used in AI applications and security testing.

---

# 🎯 Learning Objectives

- Understand how LLMs process prompts
- Learn the anatomy of an effective prompt
- Differentiate between system and user prompts
- Explore advanced prompting techniques
- Apply prompt engineering through practical challenges

# 🛡️ AI Security Relevance

Prompt Engineering is a core concept in AI Security because both attackers and defenders rely on prompts. Understanding prompt design is essential for identifying prompt injection attacks, testing LLM behavior, and developing secure AI applications.
